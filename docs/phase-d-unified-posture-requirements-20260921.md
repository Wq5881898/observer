# D 阶段统一姿态事件需求（2026-09-21）

## 决策

D 产品不再把 `posture_deviation` 和 `ergonomic_risk` 显示、计时或保存为两类事件。两者都来自同一份个人姿态校准，而且真实使用中经常由同一个动作先后触发，继续分成“姿态”和“健康”会让用户误以为发生了两件不同的事。

从本次调整起，产品只形成一种“姿态”事件，含义限定为：**当前可观测的头部或上身姿态持续偏离个人校准基线**。它是非医学软提示，不评价疾病或健康损害，也不计入专注总分。

## 产品规则

1. 底层继续计算原姿态组合证据和原人体工学候选特征，避免丢失歪头、低头、肩线不平、躯干倾斜、头眼补偿等已有观测能力。
2. 产品层将两路结果合并为一个 `posture_deviation` 信号：任一路为 violation 时，统一姿态信号为 violation。
3. 统一姿态信号连续成立 20 秒后只生成一个“姿态”事件；恢复连续 2 秒后结束。
4. 姿态事件始终零扣分，与专注违规时间及总分无关。
5. 姿态提醒使用柔和短音和浅色横幅，同一会话内 5 分钟最多提醒一次；冷却期间的独立事件仍记录，但不重复发声。
6. 新会话不再创建 `ergonomic_risk` 规则、累计项、提醒或事件。
7. 旧会话中的“健康提示”属于当时已发生的历史事实，不迁移、不改名、不重新计时。
8. C 阶段研究工具仍可保留独立 `ergonomic_risk` 输出，用于解释底层特征；本次调整只改变 D 产品语义。

## 验收

- 同一个动作同时满足两路底层条件时，只出现一个姿态事件和一次提醒。
- 只有原 `ergonomic_risk` 路径异常时，仍能形成统一姿态事件，不因合并而漏掉。
- 姿态持续不足 20 秒不形成事件；达到 20 秒形成；恢复 2 秒结束。
- 新会话摘要只显示一个姿态累计异常项，不显示健康提示累计项。
- 旧会话仍能正常查看原“健康提示”记录和图片。
- 所有姿态事件保持零扣分。
