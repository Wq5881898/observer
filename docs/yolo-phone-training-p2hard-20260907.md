# Observer YOLO P2 困难样本训练报告

日期：2026-09-07
实验：`yolo11n-phone-s96-p2hard-small-20260907`

## 1. 目的与结论

本轮用于验证：把 P2 的新手机外观和四个边缘位置加入训练后，是否能改善旧模型在 P2 左右/顶部的漏检。

结论：**P2 边缘困难样本的学习目标已经达到，且新的 P3a 真人会话四个边缘位置与四个 recovery 全部通过；但随后发现当前微调权重对完整、居中的正常手持手机出现严重回归。YOLO11 原始 COCO 权重具备该能力，退化来自当前小样本微调方案。当前权重不得进入正式替换，也不应直接进入 P3b；必须先修复完整手机回归并同时保住边缘能力。**

## 7. 原 S96 回归

报告：

必须区分两个口径：

- 存在性：图片中有无任何手机候选，接近 Observer 事件触发需求；

未匹配框只出现在有手机图片，主要反映重复候选或框位置/尺寸与人工框不一致，不等同于无手机误报。由于手机规则还会使用框的位置关系，定位退化仍需在 P3 live 中观察，不能完全忽略。

批次级结果为 `TP=4`、`TN=4`、`FP=0`、`FN=0`，Precision、Recall、F1 均为 1.0，所有帧可观测。四个阳性场景的最长连续 violation 均约 12 秒，四个 recovery 最长 violation 均为 0 秒。

额外检查 `derived_samples.jsonl` 后确认：四个阳性段的 `raw_signal_state` 已经连续为 violation，恢复段连续为非 violation。因此本轮通过不是由 1.5 秒 retain 机制桥接偶发漏检造成的。录像中点人工抽查也确认四个动作与场景标签一致。

这一结果相对 P2 训练回放中的 E02 断续现象有明显改善，说明新增困难样本对本机、当前手机的新会话有效。其证据强度仍只属于“同设备会话 holdout”；同一测试者、背景、摄像头和手机外观与训练数据相近，不能据此推断对其他手机和真实长时使用的泛化能力。

## 10. 完整手机回归检查

用户在 P3a 预览阶段发现：完整手机出现在画面中央或侧面时可能不显示 violation。预览阶段不在 P3a 调试录像的保存范围内，因此使用早期、未参加本轮 P2 标注的两段“正常手持手机”录像做离线复核：

```text
phone_baseline_b04_one_hand_phone
phone_baseline_b11_two_hands_normal
```

录像画面确认手机完整、清晰、位于人物身前的中央区域。阈值 0.25 下，当前微调模型结果为：

| 历史场景 | 阳性帧 | 检出率 |
| --- | ---: | ---: |
| B04 单手完整手机 | 0/154 | 0.0% |
| B11 双手完整手机 | 4/154 | 2.6% |

即使把阈值降至 0.10，B04 也只有 6/154（3.9%），B11 只有 27/154（17.5%），因此这不是把 0.25 稍微调低就能解决的问题。

作为能力对照，使用未经项目微调的官方 YOLO11n COCO ONNX 权重，对两段录像各抽取 25%、50%、75% 三个完整手机帧检查。6/6 帧都检测到 COCO `cell phone` 类，置信度范围约为 0.700～0.845。由此可以区分：

- YOLO11 架构和官方预训练权重本身具备完整手机检测能力；
- Observer 的规则层接受画面任意位置的已确认手机，不存在只允许边缘手机的区域限制；
- 当前失败来自项目小样本微调后的权重，而不是 YOLO 没有这项能力；
- 当前训练集主要由边缘裁切手机和无手机帧构成，数据分布过窄，出现了对普通完整手机的灾难性遗忘/偏置。

本项将作为下一轮训练的强制回归门：完整手机与边缘手机必须同时通过，任何一项失败都不得进入 P3b。
