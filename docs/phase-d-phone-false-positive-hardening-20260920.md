# D 手机误报保护修正

日期：2026-09-20  
状态：项目所有者已提供人工真值并批准修正。  
适用范围：真实产品中的可见手机候选跟踪；不改变10秒事件门槛、合并计时和时间比例评分。

## 1. 已确认问题

60分钟真实会话 `01dcbacb-d98e-4b2e-afb2-17bd0abaad7d` 在没有手机的情况下形成了一项21.671秒可见手机事件。项目所有者确认首尾图之间也保持相同的无手机场景，因此人工真值优先于模型输出，该事件确定为误报。

本轮没有开启测试取证，无法恢复中间原始检测框；不能根据缺失证据猜测曾短暂出现手机，也不能直接修改模型阈值。两张保存图片使用冻结模型和0.25阈值离线重跑均为零手机框。

## 2. 根因审查

阶段C冻结事件链明确使用：

- 单类手机模型 `observer-phone-s304-e2b.onnx`；
- 分数阈值0.25；
- 候选保留1.5秒；
- 中心跟踪距离0.18；
- 连续10秒才成立事件。

D真实产品只显式传入模型和0.25阈值，候选保留时间回落到视觉探针默认的2.0秒。阶段C自然使用已经观察到无手机背景会产生低置信、间歇性的短误检；1.5秒保留下最长只有约3秒，不会形成事件。延长到2.0秒会扩大跨检测缺口的连接范围，构成未经批准的参数漂移，也是本轮持续误报的可修正风险。

## 3. 修正规则

1. D真实产品必须显式传入并记录0.25、1.5秒和0.18三个冻结参数，不再依赖视觉探针默认值；
2. 不提高0.25阈值，避免损害已经通过的低边手机召回；
3. 不改变10秒事件门槛、两次邻近原始命中确认和手机可见性语义；
4. 1.5秒没有新的邻近原始手机框时清除候选，不能继续把旧框当作当前手机；
5. 会话身份必须保存实际手机阈值、保留时间、跟踪距离和确认命中数，便于历史审计；
6. 测试取证开启时仍按2秒序列保存，以便再次误报时定位具体错误对象。

## 4. 验收

- 自动测试覆盖1.5秒边界：小于等于边界的短缺口允许桥接，超过边界立即清除；
- 阶段C当前冻结模型的P7数据离线复核保持通过：清晰中、左、右手机原始命中为100%，低边E01原始命中率75%，1.5秒保留下连续跟踪仍超过10秒；
- P7八个无手机、恢复和充电宝负例仍不形成手机事件；
- 下一轮真实自然使用开启测试取证，若再出现手机误报，以人工真值和图片序列继续修正，不以数据库标签覆盖人工判断。
