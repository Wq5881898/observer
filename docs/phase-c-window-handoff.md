## 3. 冻结产品语义

| 能力 | 类型 | 默认行为 |
| --- | --- | --- |
| 在席/离席 | 硬信号 | 连续 20 秒提醒并扣分 |

已经改成统一物体违规。当前不值得继续追求手机与相似物体的极端精细区分，但也
不能在最终报告中谎称它们已经正式属于手机规则。

## 6. 明确延期且不阻塞 C 的问题

- 极低露边、严重遮挡手机可能漏检或判 `unknown`；
- 相似物体、衣物或画面边缘可能产生短手机假框；
- 当前同人、同设备证据不能外推为跨用户、跨手机或跨摄像头泛化；
- 眼镜反光可能使近距离右下 gaze 不可靠；头部仍朝屏内时应安全处理而非扣分；
- attention 存在明显会话波动，只能作为软信号；
- 姿态和人体工学只作趋势提示，不是医学诊断；
