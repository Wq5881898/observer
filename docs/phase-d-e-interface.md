# D 到 E 的极简接口交接

日期：2026-09-12  
状态：D阶段关闭后的正式交接接口；只描述当前已实现边界，不承诺完整E功能。

阶段E已改由独立任务窗口继续。接手顺序、E/F范围、共享文件约束和起始提示词见[阶段E独立窗口交接](phase-e-window-handoff-20260921.md)。本文件继续作为D固定技术接口，不由E静默改写。

## 1. 线程与资源归属

`ProductStore` 和 `SessionService` 必须由同一个产品工作线程创建和调用。Qt主线程只负责控件与提醒呈现，通过命令队列向工作线程提交操作，通过不可变快照更新界面。摄像头、视觉探针和资源采样器都归工作线程所有；结束、异常或窗口关闭时由工作线程释放。

同一产品数据目录只允许一个 `RuntimeLock` 持有者。桌面、控制台运行入口和全量删除都必须先取得锁，再打开或迁移产品数据库；第二个运行入口和运行期间的全量删除不得在确认归属前触碰数据库。以后增加托盘或IPC时仍须复用这个锁和同一个工作线程，不能再建立第二个写库或摄像头会话。

## 2. E 可以复用的边界

| 边界 | 当前入口 | 约束 |
| --- | --- | --- |
| 会话 | `SessionService.start/pause/resume/end` | 所有时间戳需单调；手动暂停冻结剩余时间，继续时顺延本次结束时间 |
| 计划 | `ProductStore.add_task/tasks/cancel_task/retry_task`、计划模板CRUD与 `SessionService.due` | 支持单次、每天、工作日和选定星期；每个任务实例只能建立一个会话 |
| 历史 | `ProductStore.history/summary/data_status` | UI只读持久化事实，不从内存重新推断分数；单条身份或资源JSON损坏时显示数据警告，不中断列表 |
| 提醒 | `ProductStore.mark_notification` | action先落库，再由UI呈现并确认；一个合并专注事件最多一次计分提醒 |
| 图片 | `ProductStore.capture/recover_evidence/delete_session/delete_all/purge` | 默认关闭；只接受产品evidence目录内的相对路径；取得运行锁后恢复原子写入中间状态；全量删除先预检全部路径；保留期清理逐会话隔离失败 |
| 数据源 | `DemoSource` 或 `CameraSource` | 提供 `identity`、`read(at)`、`close()` 和当前 `frame`；真实源可执行一次有界重连 |
| 资源 | `SessionResourceTracker.begin/sample/finish` | 5秒低频、有界采样；失败不影响观察和计分 |

数据库打开时会在摄像头初始化前验证完整性、现有外键数据、六组关键外键及级联规则的定义、schema、v1至当前版本连续且无缺口的迁移账本、单会话和计划实例唯一索引，以及截图开关、测试取证开关和保留天数的类型与范围。schema v9保存计分版本、合并专注事件、分项区间、时间并集和多图证据序列。校验失败应直接显示原因并停止启动，E不得用默认值掩盖损坏数据。

## 3. UI快照与命令

当前桌面工作线程发布：会话状态、剩余时间、任务列表、历史列表、截图开关、本地数据概览、最新信号状态和模拟信号。E可以改变布局或呈现方式，但不应让主线程直接访问SQLite或视觉对象。

当前命令集合为：开始、暂停/继续、结束、计划休息、当前会话延长、添加/取消/重试任务、重复计划CRUD与启停、查看/删除会话、清理过期记录、开关截图与测试取证、确认提醒和切换模拟信号。新增功能优先扩展命令和快照，不绕过 `SessionService` 直接改会话表。

任务、历史和截图设置等短操作可以从第二终端通过独立SQLite连接执行；运行锁只阻止第二个长驻运行入口和运行期间的全量删除。SQLite保持WAL和短事务，外部命令不得长期持有事务或直接控制摄像头。

## 4. 固定语义

- 离席、可见手机和离开屏幕是计分信号；各自达到门槛后合并为专注违规事件，重叠秒数只计算一次。原姿态与人体工学候选合并为一个零计分“姿态”软提示。
- 新会话按 `(计分时长-违规时长)/计分时长` 评分；覆盖低于80%显示证据不足。旧会话保持 `points_v1` 历史分数。
- `unknown` 不产生有效观测或违规时长；断流、暂停与计划休息不能连接前后的持续违规。
- 真实入口在打开摄像头前验证C冻结模型与默认配置身份。
- 每次会话保存实际模型、配置、profile和会话头姿基线身份。
- 真实源身份包含核对、模型、摄像头、基线和总启动秒数；桌面另保存点击到会话建立的完整准备秒数，E可选择呈现但不得据此改变计分。
- 报告导出和趋势图按项目所有者要求暂不实现；托盘、后台服务和跨终端会话控制仍属于后续E/F。重复日程已经实现。

## 5. D关闭交接验证

自动集成验收使用临时产品目录串联：到期任务 → 建立会话 → 重叠离屏/手机信号 → 单个合并事件和一次提醒 → 时间并集评分 → 提醒确认 → 暂停/恢复 → 正常结束 → 关闭并重开数据库 → 核对任务、摘要与交付状态 → 删除会话。v1至v9迁移、旧分数保留、提醒等待上限、短候选排除、多图证据和统一姿态均有确定性回归。真人提醒、真人截图、合并评分场景和60分钟真实产品资源门也已完成。D关闭时全套288项自动测试通过。

历史读取故障注入会破坏单条会话的身份JSON和资源汇总字段；`history` 仍返回全部记录并标记异常，`summary` 返回可用账本及数据警告。E应直接呈现这些安全字段，不能在主线程再次解析原始JSON。
