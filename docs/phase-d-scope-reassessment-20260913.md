# D 阶段范围复核：从极简首轮恢复 Agenda 主体

日期：2026-09-13

状态：已批准并完成；D8～D10、本次延长和最终验收均已关闭，阶段D于2026-09-21通过。项目所有者同意纳入D8～D10全部推荐能力，并要求集中放入独立“高级计划”标签，避免影响默认极简页面。本文保留当时恢复范围的理由和实施选择。

## 1. 为什么需要重开范围

原始 D 基准把本地产品闭环定义为 SQLite、Agenda、会话、报告和证据管理，并明确包含单次及每周重复任务、计划休息、任务豁免、计划编辑和执行实例。之后项目所有者要求先做功能与界面极简的首版，报告导出也可暂缓。开发文档因此把重复计划、复杂休息策略和规则配置写为“暂不做”，目的是先打通真实闭环，不是永久删除原始 D 需求。

当前实现已经证明单次任务、真实观察、提醒、扣分、历史、证据、删除、异常恢复和长期资源预算成立。此时直接结束 D，会留下“只能手工安排一次任务”的产品：用户无法维护日常计划，计划结束后还要重复录入，也没有受规则认可的休息。这与原始 Agenda 目标有实质偏离。

## 3. 推荐纳入 D 的具体形态

### D8 每日计划与重复执行

计划表单保持一个任务名、开始时间和时长，增加一个重复选择：单次、每天、工作日、每周选定星期。界面按系统本地时间输入；存储保留时区身份，调度层必须覆盖 DST 不存在时间和重复时间的确定行为。暂不提供任意 cron、月度规则或跨时区编辑界面。

界面实现不改动默认专注页面：立即开始、单次定时、暂停和结束保持原有控件数量。`Observer`标题下方使用一级导航“专注 / 历史 / 高级计划”，三个页面各自占满内容区；重复模板的创建、编辑、启用、停用和删除都放在高级页，今日摘要显示在页首。计划休息、允许离屏资料及当前会话延长也只在高级页出现。用户不打开高级页时，现有使用流程和视觉密度不变。

数据层新增计划模板，现有 `tasks` 继续表示一次执行，并通过可空 `plan_id` 关联模板。这样现有单次任务和 session→task 关系不需要重建；重复模板只负责生成未来执行实例。`plan_id + starts` 唯一，保证重启或反复刷新不会重复生成同一次任务。

只预生成一个有限未来窗口，到期后滚动补充。修改模板只重建尚未开始的未来实例；已结束、错过、冲突或已关联会话的实例保留。用户可以启用、停用和删除模板，删除模板不得删除历史会话。

目标 Windows 环境原先无法直接加载 `America/Denver`，原因是标准库 `zoneinfo` 在Windows没有系统IANA时区库，项目当时也没有 `tzdata`。实现现已加入CPython维护的 `tzdata` 和用于取得本机IANA名称的 `tzlocal`，再以标准库 `zoneinfo` 执行有限规则。春季不存在的本地时刻跳过并记明原因；秋季重复时刻只生成第一次，均由确定性测试锁定。

不建议按原草案直接引入 APScheduler 3.x。当前产品工作线程已经轮询数据库到期实例，新增第二个调度器不能让关闭的程序自行唤醒，反而增加运行状态。APScheduler 3.11.3虽是当前稳定3.x版本，但官方仍明确提示 `CronTrigger` 在DST切换时可能多执行或少执行；四种有限重复规则仍需产品自己定义上述语义。若以后进入后台服务、复杂日历或系统唤醒，再在E/F重新评估调度器。

### D9 休息、延长与最小任务豁免

增加“休息”状态和明确的开始/结束操作。休息期间停止规则连续计时、从 eligible 中排除并释放摄像头；结束后重新打开摄像头并从新鲜观测开始。首版计划休息只支持关闭，或“每 N 分钟休息 M 分钟”，不支持多段自定义时间表。

任务计划结束时间继续按墙钟固定，休息不自动推迟结束，避免与下一计划重叠；用户需要更多时间时可显式延长当前任务。延长只修改本次会话截止时间，不回写计划模板。

任务模板增加一个默认关闭的“允许离屏资料”选项。开启后只豁免本次 `attention_away` 提醒与扣分；离席和可见手机规则不变。会话开始时保存实际策略快照，后续编辑模板不追溯改变已开始会话。

### D10 今日视图与完整验收

在现有“计划”页内显示今日执行实例和后续计划，区分待开始、运行、完成、错过、冲突和失败。增加极简今日摘要：计划数、完成数、实际观察时长、计划休息时长、硬规则扣分和最低硬信号覆盖。它读取现有持久化事实，不生成导出文件，不增加趋势图。

自动验收覆盖重复生成幂等、编辑只影响未来、停用/删除、跨重启、重叠冲突、本地日期边界、DST、计划休息不拼接违规、休息时长不进入 eligible、延长只作用本次会话、策略快照不可变和旧 v6 数据迁移。目标电脑再完成一次短的“重复计划到点→休息→恢复→延长→结束→今日摘要”真人闭环。
