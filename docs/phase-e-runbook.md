# Observer 阶段 E 桌面使用说明

日期：2026-09-21  
当前实现：E1 托盘/窗口、E2 可配置任务通知、E3 连续性与 Windows 电源消息、E4 单实例唤醒均有自动测试；E5 已有资源诊断。集中实机测试与阶段结论待完成，统一步骤见 [E 收敛与测试清单](phase-e-closeout-test-plan-20260922.md)。

## 启动

从项目根目录执行：

```powershell
# 模拟模式；不打开摄像头，使用独立数据目录
.\.venv\Scripts\python.exe -m observer product --data-dir data/product-demo gui --demo

# 真实模式；沿用现有冻结模型与个人校准
.\.venv\Scripts\python.exe -m observer product gui
```

计划、会话、截图、计分与历史的使用方式继续见 [D 使用说明](phase-d-runbook.md)。E1 改变窗口关闭行为：系统托盘可用时，点击右上角关闭只隐藏窗口，当前会话和定时计划继续运行。窗口底部始终说明此行为。

## 窗口与托盘

| 操作 | 行为 |
| --- | --- |
| 最小化 | 保留任务栏入口，当前会话继续运行 |
| 关闭窗口 | 有可用托盘时隐藏；不会暂停观察或释放正在使用的摄像头 |
| 点击/双击托盘图标，或菜单“显示窗口” | 恢复同一个窗口；不创建新工作线程、会话或摄像头 |
| 托盘“暂停当前会话” | 与窗口暂停按钮相同：冻结倒计时、关闭摄像头 |
| 托盘“继续当前会话” | 继续原暂停会话，重新准备摄像头 |
| 托盘“结束当前会话” | 正常结束并保存会话，程序继续运行，可执行后续计划 |
| 窗口“退出程序”或托盘“退出” | 保存/中断当前会话，等待摄像头、模型、数据库和运行锁释放后退出 |

托盘菜单状态与窗口按钮同步；启动或其他命令尚未处理完成时，不接受重复会话控制。计划休息期间不提供手动“暂停/继续”，但可以结束会话或退出。

明确退出后窗口会显示收尾状态，保持可响应；正在加载的模型完成并释放之前，程序不会假装已经退出。原生模型或摄像头驱动永久阻塞的强隔离属于 E3，目前尚无强制退出超时保证。

## 降级行为

- Windows 挂起/自动唤醒消息、运行停顿超过 10 秒或明显时钟异常，都会让运行中/计划休息中的会话保存为中断并释放摄像头，提示重新开始；手动暂停保持暂停。电源消息不能区分睡眠和休眠，双时钟检测也不能确定停顿原因。真实睡眠点验仍待完成。

- 系统托盘不可用时，底部说明“关闭窗口将结束会话并退出程序”，关闭沿用退出流程。
- 隐藏期间托盘不可用，会在约 1 秒内检查并恢复窗口，防止失去控制入口。
- 产品工作线程停止后，会恢复窗口显示停止状态；可关闭窗口退出。
- 同一数据目录第二次启动会向已有实例发送本地“显示窗口”信号，然后自行退出；不会打开第二个数据库或摄像头。不同数据目录仍可独立运行。运行锁继续处理启动竞争和异常情况。
- 专注违规与姿态仅使用原声音和窗口提示，不发送系统通知。窗口底部“定时任务系统通知（到点及启动失败）”默认开启，可关闭并自动保存；点击任务通知可恢复窗口。状态显示“已提交”不代表系统已展示或用户已读，Windows 通知权限或免打扰可能阻止显示。

每天 10:00–11:00 学习：在高级计划中设置每天 10:00、时长 60 分钟，并保持 Observer 运行（可以隐藏到托盘）和电脑唤醒。到点会先通知“学习时间到了”，再准备摄像头并开始任务；启动失败另行通知。关闭通知开关不停止计划执行。程序退出或电脑睡眠时不承诺到点提醒；错过/冲突任务继续沿用已有处理方式。
