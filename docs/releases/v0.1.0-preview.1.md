# Observer v0.1.0-preview.1

Windows x64 便携预发布版，2026-10-10。项目所有者授权先发布一个版本并同步 GitHub；发布于现有私有仓库，保留 E/F 未完成的验收安排。

## 下载及启动

下载 Release 附件 `Observer-0.1.0-preview.1-windows-x64.zip` 和 `SHA256SUMS.txt`。用 PowerShell 的 `Get-FileHash -Algorithm SHA256` 核对 ZIP，解压完整目录；不需要安装项目 Python 或 uv。

本版是 PyInstaller onedir，含 `Observer.exe` 和诊断入口 `Observer-diagnostic.exe`。资源共用 `_internal`，请保留整个 `Observer` 文件夹。无安装器、开机启动或自动更新。

首次试用建议显式使用隔离模拟目录：

```powershell
& '.\Observer\Observer.exe' product --data-dir "$env:LOCALAPPDATA\Observer\preview-demo" gui --demo
```

`--demo` 不打开摄像头。关闭窗口在托盘可用时隐藏；完全退出请用“退出程序”。默认真实模式数据位于 `%LOCALAPPDATA%\Observer\product`，个人校准位于 `%LOCALAPPDATA%\Observer\calibration\default.json`。旧源码版数据不会自动迁移或覆盖。

可在解压根目录执行 `./validate_windows_portable.ps1`，用 Windows PowerShell 5.1/7 做无摄像头的模型和 GUI 自检，结果写到新的 `validation-results` 子目录。更多操作见压缩包里的 `PORTABLE-VALIDATION.txt`。

## 本版内容

- 违规（手机、离席等）使用两声短提示；姿态不正使用一声柔和提示。
- 包内模型及配置定位不依赖工作目录；支持中文/空格程序及数据路径。
- 用户数据和个人校准独立于程序目录；窗口版具有本地启动错误日志。
- 冻结会话记录可追溯的源码树摘要及构建身份；附完整文件 SHA-256 清单。
