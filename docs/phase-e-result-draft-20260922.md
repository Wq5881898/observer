## 4. 偏差、已知限制与回退

1. 阶段基准曾列摄像头/推理进程隔离；实测父子重复模型达到 541.1 MB，超过 500 MB 预算。生产实现保留单工作线程、连续性保护和一次重连。原生驱动永久阻塞时仍无法抢占；真实故障若满足 [隔离触发条件](phase-e3-isolation-decision-20260922.md)，再单独重开隔离方案，不在本次收尾扩展。
2. Qt 提交系统通知不代表 Windows 展示、用户看见或已读；通知关闭/免打扰不影响任务执行和应用内状态。
3. 程序退出或电脑睡眠时不承诺定时任务准点通知；错过/冲突任务按既有产品状态处理。
4. 若托盘/系统通知在目标电脑不可靠，优先回退到窗口、应用内横幅/声音与现有单工作线程；若 E4 唤醒失败，保留运行锁和手动启动方式。回退不得重算历史、改变 D 评分/证据/隐私语义。
