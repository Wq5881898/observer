Observer F 内部候选独立验收包

本包用于独立 Windows x64 环境的验收，不是安装器或正式发布。
不需要 Python、uv、源码仓库或管理员权限。保留整个 Observer 文件夹。
候选的第三方分发许可仍待审查，仅供已授权的内部验证使用。

1. 转移前核对 ZIP 的 SHA-256 与发送端 transfer-receipt.json。
   在另一台没有 Observer 源码/开发环境的 Windows 机器上解压 ZIP。
   可解压到含中文及空格的路径；不要直接从压缩文件内运行 EXE。

2. 在解压目录打开 64 位 Windows PowerShell，执行：

   .\validate_windows_portable.ps1 -IndependentMachine

   也可用已安装的 PowerShell 7。脚本兼容 Windows PowerShell 5.1。
   如果系统执行策略阻止脚本，保留错误并按设备管理规则处理；
   本验收不要求关闭安全软件、以管理员运行或降低持久执行策略。
   -IndependentMachine 只记录操作者对独立机器条件的声明，
   脚本不会据此自动宣称不存在 Python/源码或“干净机器通过”。

3. 自动检查校验完整文件清单，使用仅含 System32 的子进程 PATH，
   去掉 Python/Qt 开发环境变量，实际加载四个模型处理合成帧，
   运行原生 Windows GUI 的模拟闭环、单实例唤醒及重开历史，
   再校验包内文件未被写入。不会打开摄像头或采用已有用户数据。

   所有结果保留在 validation-results/<唯一编号>；
   summary.json 必须为 passed，两份候选报告必须为 passed。
   GUI 自检会短暂显示模拟窗口；请等自动退出，不手动关闭它。
   脚本失败时保留全部日志，不删除失败目录后假装从未失败。

4. 人工点验使用另一个全新隔离目录。不要直接无参数双击
   Observer.exe，以免点验采用已有个人数据；使用隔离模拟目录。
   请为 Observer.exe 创建测试快捷方式，目标填写如下完整命令，
   替换路径，并把“起始位置”设为一个无关的现有目录：

   "C:\解压目录\Observer\Observer.exe" product --data-dir "C:\隔离模拟点验" gui --demo

   双击该快捷方式，检查中文界面、开始→暂停→继续→结束，
   一轮会话只有一条历史。关闭窗口后检查托盘图标是否可见，
   从托盘恢复；再次双击快捷方式应恢复已有窗口。
   用“退出程序”退出，再次打开应保留历史且不报运行锁占用。
   这只验证模拟快捷方式冷启动；真实无参数冷启动另保留待测。

5. 在模拟界面启用“定时任务系统通知（到点及启动失败）”，
   添加一个短定时任务，隐藏窗口，实际观察通知是否展示、
   点击是否恢复窗口，观察提醒出现时是否听到应用提示音。
   任务系统通知和规则提醒声音是不同触发路径；没触发规则
   提醒不能把系统通知声音当作应用提醒声音已通过。
   没有看到/听到就记待测或失败，不按日志中的“已提交”记通过。

6. 将人工观察写入对应 manual-results.json；记录机器是否确实
   缺少 Observer 仓库/开发环境、解压路径类型、实际操作结果，
   必要时附截图及失败日志。保持自动 summary.json 原始内容。
   日志可能包含本机路径；仅向项目所有者提供必要的内部证据。

E 摄像头恢复和 60 分钟门已完成，不需重复。
